# 先読みの見直し(2026-10-03、まおうの錬金ランプから)

利用者の指摘「まおうの錬金ランプの打ち方は無駄が多い。集中力の使い方の効率化が必要」から始めた調べと直し。
画面に出る推奨手は先読み(`stratMCAsync`・`mc-pool.js`)なので、先読み無し(貪欲)だけでなく先読みの判断も調べた。

## 1. 分かったこと

### 1-1. 先読みは、誤差でたまたま良く見えた手を選んでいた

- 先読みは、貪欲の上位8手を640回ずつ試し打ちし、貪欲の1位より t > 0.5 で良く見えた手に乗り換える。
- 640回の見積もりは誤差が ±2.5pt ほどある。候補が7つあると、候補の本当の価値が全部同じでも、約70%の局面で
  どれかが誤差だけで t > 0.5 になる(基準 t>1 で47%、t>2 で11%)。
- 例: まおうの錬金ランプの1900℃(火力上げ3回の後、全マス0。毎局同じ局面)。

  | 候補 | 先読みの見積もり(640回) | 本当の価値(3600回の平均) |
  |---|---|---|
  | 超4連打ち(貪欲の1位) | 基準 | 60.3% |
  | 左右打ち AB(先読みが選んだ) | +2.81pt | 57.1%(−3.2pt) |
  | 熱風おろし C | +2.66pt | 57.0% |

  盤面は対角線で折り返して同じ形なので、左右打ち AB と上下打ち AC は同じ価値のはずだが、見積もりは +2.81pt と −0.47pt だった。
- 試し打ちの乱数を「何手目・どのマス」でそろえても、誤差は変わらなかった(±2.47 → ±2.59)。違う手を打つと後の展開が
  別物になるので、試し打ち1回ごとの差が本質的に大きい。

### 1-2. 測り方(局面ごとに試し打ちを残す)

先読みの局を何百局も打つと何時間もかかり、2〜3pt の差は見分けられない(1700局ほど要る)。そこで、局面を集め、
候補ごとの試し打ちの結果を1回ずつ記録して、決め方ごとの良し悪しを計算で比べた。

- 局面: 貪欲の局から、先読みが走る局面を1局につき1〜2個選ぶ。
- 試し打ち: 候補ごとに 2560〜3600回。試行 j の乱数はアプリと同じ(`stateSeed` と j)。
- 選ぶのに使う試行(j < SEL)と、良し悪しを測る試行(j ≥ SEL)を分ける。同じ試行で測ると、たまたま良く出た手が良く見える。
- 値は「その手の後は貪欲で打った時の大成功率」。実際の局はその後も先読みで打つので、局全体の差はこれより小さいかもしれない。

### 1-3. 決め方ごとの結果(貪欲の1位のまま打つのと比べた得、1局面あたり)

| 決め方 | まおうの錬金ランプ80局面 | 6商材240局面 | 試し打ちの量 |
|---|---|---|---|
| 今(640回・t>0.5) | 基準(貪欲より +1.09pt) | 基準(+1.51pt) | 1倍 |
| 乗り換えの基準を上げる(t>1〜3) | −0.2〜−0.7pt | −0.02〜−0.72pt | 1倍 |
| 乗り換えの基準を下げる(t>0〜0.25) | −0.08pt | −0.08〜−0.10pt | 1倍 |
| 全候補に一律に足す(上限1280回) | +0.31pt(±0.15) | +0.10pt(±0.05) | 1.6倍 |
| **際どい候補にだけ重ねる(レース、上限1280回)** | **+0.33pt(±0.15)** | **+0.11pt(±0.06)** | **1.3倍** |
| いつも2560回 | +0.41pt(±0.17) | (測れず) | 4倍 |

- 6商材: 超かがやきの樹液・超あまつゆのいと・超ようせいのひだね・ブルームシールド・虹色のオーブ・光の鍛冶ハンマー。
  どの商材も、一律に足す決め方で今より悪くならなかった(+0.02〜+0.22pt)。
- 6商材は、+400% に変える前のエンジン(点灯マス +500%)で測った。

### 1-4. 先読みを通らない決め打ち

まおうの錬金ランプの1局の手(貪欲・種88):

| 決め方 | 回数/局 |
|---|---|
| 先読み | 約11.4 |
| 最後の1マスの総当たり | 約3.2 |
| 序盤の火力上げ・開始直後 | 3 |
| 会心ターンの狙い打ちなどの決め打ち(boostAim) | 約0.88 |

決め打ちの局面80を、決め打ちの手を先頭にした候補(`early`)で試し打ちすると、先読みが選んだ手の方が
**+1.21pt(±0.35)** 良かった(34%の局面で乗り換える)。

### 1-5. 候補の数

候補を40手まで広げて試し打ちすると(80局面)、本当の価値で一番良い手が上位8手の外にあった局面が22。
貪欲は、ふつうのターン・半減ターンでのねらい打ち・上下ねらい打ちを上位に置きすぎ、たたく・てかげん打ち・2倍打ち・上下打ちを
下に置きすぎる傾向があった。ただし、候補16手にしても今との差は +0.15pt(±0.10)、全候補に足す・レースと合わせると
上位8手の時と同じ(+0.41 / +0.43pt)で、計算が2倍になる分だけ損だった。
貪欲の重み(cap・te・boostAim)を狙い系を好まない側に動かすと、先読み無しの率は下がった(cap 12: −8.0pt、boostAim 0: −1.7pt)。

### 1-6. 序盤

| 局面 | 手(試し打ち4000回の平均) |
|---|---|
| 1300℃(全マス0) | 火力上げ 59.5% / 超4連打ち 54.7% / 4連打ち 53.5% |
| 1600℃(全マス0) | 火力上げ 57.6% / 4連打ち 55.1% / 超4連打ち 52.5% |
| 1900℃(全マス0) | 超4連打ち 60.3% / 左右打ち AB 57.1% / 熱風おろし B 57.0% |

序盤の「火力上げ×3 → 超4連打ち」は、どの手も一番良い手。1850℃は、1手目で会心が出た局面では別の手(4連打ち・上下打ち)が良いことがある。
序盤を決め打ちにする比較(先読みあり・種77・600局): 65.5% → 67.3%(片方だけ 111 対 122、z=0.72)。
レースを入れた先読みは1900℃で超4連打ちを選ぶので、序盤の決め打ちは入れていない。

## 2. 入れたもの

- **レース**(`engine.js` の `MC_RACE`・`mcMore`、`mc-pool.js`、`mc-worker.js`): 最初の640回で、基準より t > 0 の候補にだけ
  640回ずつ重ね、t が 0 以下に落ちた候補を外す。一番良い t が 3 以上になるか、上限(1候補1280回)に着いたらやめて、t > 0.5 の中で
  t が一番大きい候補を選ぶ。既定にした(試し打ちを1280回より多くしている輝紋章の盾・幽紋刀は変わらない)。
  - 確かめたこと: 切った状態では前のエンジンと同じ手(20局面)。入れた状態では記録で計算したレースと同じ手(40局面)。
    Worker 側と画面側も同じ手(候補8手・16手)。
- **まおうの錬金ランプの決め打ちも先読みにかける**(`mc: { gate: 0, early: true }`)。

## 3. 局の率での確かめ

まおうの錬金ランプ・先読みあり・種77・乱数テープで、前の先読みと、レース+決め打ちも先読みを、同じ局どうしで比べた。

| 局数 | 前の先読み | レース+決め打ちも先読み | 差(95%の範囲) | 片方だけ大成功 |
|---|---|---|---|---|
| 200 | 65.5% | 65.0% | −0.5pt(±9pt ほど) | 41 対 40(z=−0.11) |
| 1005 | 66.0% | 67.6% | +1.6pt(−2.4〜+5.6pt) | 200 対 216(z=0.78) |

- 局全体では、悪くなる兆しは無い(悪くても −2.4pt まで)。良くなったとまでは言えない。
- +1.6pt をはっきりさせるには約6000局が要る(1700局まで続けても範囲は ±3.1pt ほどにしかならない)ので、
  利用者の指示で 1005局で終えた(2026-10-03)。

| 案 | 結果 |

## 5. 道具(scratchpad。次に使う時は写して使う)

- `reg/run.js 局面.json 出力 N worker workers`: 候補ごとの試し打ちを記録する。`EARLY=1`・`KALL=40` で候補を変える。

## 6. 幽紋刀: 先読みの試し打ちと実際の打ち方のずれ(2026-10-03)

利用者の指摘「幽紋刀は先読みありの方が大成功率が低い。原因の調査と改善は急務」から調べた。

- **ずれはある:** 試し打ちの中では、2マス残りの総当たり(`ldp2`)と、全マス到達後の仕上げのやり直し(`er`)を使わない
  (`stratB0` の `!IN_ROLLOUT`、`mcRolloutBody` の `erRoll` 既定 0)。打ち始めから続けた大成功率は、試し打ちの打ち方 35.6%、
  実際の打ち方 39.8%(各2000回)。実際の打ち方の方は、先読み無しの対局(種66・乱数テープ・1000局)の 40.0%(37.0〜43.0%)と一致する。
  影響を受けうる商材は、戻りの地金36・`ldp2` を使う5の、計41商材。
- **ずれは判断を悪くしていない:** 先読みが走る80局面で、候補ごとに同じ乱数で両方の打ち方を2560回ずつ打ち、
  選ぶのに1280回、答え合わせ(実際の打ち方)に残り1280回を使った。

  | 選び方 | 先読み無しの1位と比べた得(1局面あたり) |
  |---|---|
  | 今の先読み(試し打ちの打ち方で選ぶ) | +0.60pt(±0.51) |
  | 実際の打ち方の試し打ちで選ぶ | +0.63pt(±0.55) |
  | 一番良い候補を知っていた場合(上限) | +1.76pt(±0.52) |

  試し打ちを実際の打ち方にすると、1回が 1.36 → 2.11ミリ秒(1.55倍)になるが、得は変わらない。入れていない。
  乗り換えの基準(t>0〜2)や試し打ちの回数(320〜1920回)を変えても、得は +0.4〜+0.8pt で、はっきりした違いは無い。
- **「先読みありの方が低い」は、正確な記録では確かめられていない:** 元になった数字は、先読みあり 39.0%(100局・前のエンジン)と
  先読み無し 43.7%(別の300局)の比較だった。今のエンジンの先読み無しは 40.0%(1000局)。局の率での先読みありの正確な記録は無い。
- 道具は scratchpad の `yum/`(`truth.js`・`eval.js`・`sel.js`・`start.js`・`speed.js`)。

### 7-6. 2マス同時の罠(trap)を4商材に入れた(2026-10-10、V2.80)
針(2マス縦・許容誤差0)で、打ち方そのものを見直した。

- **2マス同時の総当たり**(scratchpad の dp2/dp2.c): 状態を (集中力 0〜260, 温度, A の残り 1〜160, B の残り 1〜160) とした約3億局面の
  総当たりを C で解き(1商材約10分、手の表 298MB)、2マスとも残り160以内になってからその手で打った(それまでは遠い方のマスを今の打ち方で進める)。
  先読み無し・乱数テープ・同じ局どうし(種44・1000局): 奇跡のさいほう針 54.7% → 63.7%(187対277、z=4.18)、
  光のさいほう針 51.9% → 64.6%(165対292、z=5.94)。表はアプリには載せられない大きさ。
  - 最初に解いた表は、ななめ打ちを片方のマスにだけ当たる手として入れていた。縦1列だけの盤では、ななめ打ち・左右打ちは盤から
    はみ出すので打てない(enumerateTargetSets)。上の値は、ななめ打ちを除いて解き直した表のもの。
  - 総当たりの手は今の打ち方と21%しか一致しない。多いのは「火力上げ」と「上下ねらい打ち(2マス)」で、上下ねらい打ちは
    奇跡のさいほう針の300局で 2000℃ 218回・1600℃ 41回、光のさいほう針で 1600℃ 122回・2000℃ 100回・1200℃ 44回だった。

- **罠の形**: 上下ねらい打ちは縦の2マスに同時に当たり、会心はマスごとに出る。会心は理想値を越える時だけ理想値で止まるので、
  「会心でなければゾーンに届かない(残り > 最大ロール)・会心なら必ず理想値を越える(2×最小ロール ≧ 残り+幅−1)」距離にいれば、
  会心したマスはちょうど理想値で止まり、会心しなかったマスはゾーンの手前に残る。たたき変化の400の倍数(威力2倍)で、この距離は遠く広い
  (奇跡のさいほう針: 2000℃ A 67〜86・B 67〜78 / 1600℃ A 59〜74・B 59〜66)。総当たりは、2マスの残りをこの距離にそろえ、
  火力上げで 2000℃・1600℃ に着けてから撃っていた。

  罠の距離で 1 にそろえる。一番近い罠の距離より近づいたら値 trapK(罠をあきらめて今の打ち方に戻る)。計画の範囲(残り trapG 以内)に
